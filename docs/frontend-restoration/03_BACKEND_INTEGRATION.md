# Backend Integration

Search parses the shareable URL, reads published courses and filter choices through the existing Supabase session client, filters by course title, subject or teacher and renders the result in the original search controls. Query and configuration errors use an explicit unavailable state. Existing course-page and session policies are used without migrations.

The next integration groups are profile and role-specific navigation, discovery and content, academic operations, communications and finance. See the route matrix for baseline status and acceptance.
